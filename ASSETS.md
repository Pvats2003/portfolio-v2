# ASSETS.md — what the /world layer is made of

The world is a painted 2.5D village (`components/world/village/`). Until the painted plates arrive it's drawn in code
(SVG shapes and gradients). The painted plates are AI-generated by Priyanshu with the prompts in
`art/plates/CHECKLIST.md` (see the table). There are no third-party models, textures or sounds.

| Asset | Where | Source | Licence |
|---|---|---|---|
| Code-drawn village (fallback) | `components/world/village/` | Drawn in code: SVG shapes and gradients | Ours |
| Painted plates | `art/plates/` (masters) → `public/world/plates/` (web) | **AI-generated** by Priyanshu with TODO: image tool name and plan, from the prompts in `art/plates/CHECKLIST.md` (1376 × 768), then upscaled 2× with [Upscayl](https://upscayl.org) before `npm run world:plates`. | Per the image tool's terms (TODO). Upscayl is free, open-source software (AGPL-3.0); that licence covers the app, not the images it upscales. |
| Sign lettering, UI panels | canvas texture + site CSS | IBM Plex Mono / Sans, already used by the site | SIL Open Font Licence 1.1 |

If a CC0 model is ever added (WORLD.md §1, escape hatch), record its name, author, link and licence here first.
